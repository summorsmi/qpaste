# 日期功能实施记录

用户要求：保持操作简单，按功能逐步实现，每个功能完成后独立提交。

1. **SQLite 存储与复制时间：完成。** 内容去重、复制事件独立保存、片段修改时间分离；事务迁移旧历史且保留原始文件，迁移仅执行一次，删除事件随内容级联。
2. **日期分组：完成。** 今天、昨天、近 7 天、近 30 天、更早按月；标题不参与键盘选择。跨日、唤醒与时区变化刷新。详情区分复制与片段修改时间。
3. **日期筛选：完成。** 搜索旁单一日期入口，快捷范围和自定义范围；按范围内的复制事件查找，结果去重，筛选不触发清理。当前范围单独显示并可一键清除。
4. **按需加载：待实现。** 分页查询与列表加载，容量与分类数量保持全量统计，避免把全部正文一次读入界面。

第一步验证：29 项相关测试通过（12 项剪贴板集成、12 项历史规则、5 项数据库）。覆盖迁移原文备份、重启不重复导入、跨天重复复制、事件重试、日期区间半开边界、事务失败回滚、未知数据库版本保留和旧有图片 / 文件 / 片段行为。

第二步验证：27 项相关测试通过（4 项日期分组、23 项剪贴板 / 鼠标 / 悬浮）。覆盖分组互不重叠、键盘编号连续、午夜变化、时区切换、夏令时 23 小时的自然日、片段修改时间与未来日期。

第三步验证：24 项相关测试通过（5 项日期、5 项数据库、14 项剪贴板）。覆盖自定义范围包含起止自然日、夏令时边界、历史来源搜索、按昨天找到今天重复复制的内容、操作旧日期结果不覆盖最新元数据、相对日期随跨日更新，以及日期筛选不删除数据或改变清理偏好。

清理仍沿用当前条数、经过时间和 5 GB 规则；本次日期展示与筛选不会更改用户已有清理偏好。

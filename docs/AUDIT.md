# 当前版本检查（2026-09-13）

基线为 `92b24b8`。检查顺序：功能缺陷、易用性与资源占用、后续功能。
使用隔离目录、命名测试剪贴板和合成数据；不向用户历史插入样例。

## 已修复：悬浮详情快速往返不显示

指针在详情出现前离开条目，随后在 250 毫秒关闭等待期间回到同一行，旧逻辑会取消显示任务又跳过重新调度，导致停留再久也不显示详情。
现在只有已显示的详情才能复用；尚未显示时重新计时。

新增测试在修复前失败，修复后全部 7 项悬浮测试通过，覆盖完整文字、长图滚动和非激活详情窗口。原生测试只注入命令行宿主无法获得的键盘焦点边界，不作为真实鼠标悬浮验收。

## 已修复：无变化的定时清理打断列表

原来每分钟检查保留策略都会重查当前列表，将 `selected` 临时置空、禁止点击、重新创建详情。即使没有任何记录被删除，也可能打断正在查看的文字选区或图片。
现在只在实际删除记录或补存成功时刷新；无变化的清理不会取消正在进行的搜索。

新增测试在修复前失败，修复后全部 5 项分页测试通过。另验证真正改变保留数量时，列表和全局统计仍更新，失败捕获补存后仍可见。

## 已优化：长文本列表摘要

标题原来先分割全文的所有行，代码识别也会创建清理后的全文。现在标题只读取首个非空行的最多 160 个字符；代码识别只检查去掉开头空白后的前缀。完整正文和搜索内容不变。
增加 Unicode 字符、换行、空白文本与代码识别回归。性能数据在本文后续测量部分记录。

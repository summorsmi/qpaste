# 列表摘要与正文按需读取

## 数据库阶段

新增独立的 `HistoryListItem`，只包含最多 160 字的标题、类型、来源、时间、收藏状态与图片标识，不包含正文、RTF 或文件路径列表。摘要使用独立版本标识，旧摘要不能读取已被修改的正文。

数据库 schema 2 → 3 补充摘要与版本列，逐条读取旧记录生成摘要，原 `payload` 字节和复制事件保持不变。升级在事务内执行，任何失败都会回滚新增字段。版本 1 与旧 JSON 也可直接升级。

`listPage` 与完整记录查询使用相同的分类、日期与全文搜索条件，但只返回摘要。正文按 ID 和摘要版本单独读取，按日期筛选时仍展示该时间范围内的来源和复制时间。

16 项核心相关测试通过，覆盖升级与失败回滚、原字段字节保留、完整正文末尾关键词搜索、日期上下文、格式保留、旧版本摘要失效，以及即使正文无法解析仍能独立读取摘要。

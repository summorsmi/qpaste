# Qpaste

一个为个人使用设计的 macOS 原生剪贴板工具。菜单栏常驻，用快捷键找回复制过的内容。

## 开始使用

安装后从「应用程序」打开 Qpaste。日常更新使用下方的安装脚本，固定替换 `/Applications/Qpaste.app`。关闭窗口后应用仍在菜单栏运行，右键菜单栏图标可以暂停记录、打开设置或退出。

默认用 **⇧⌘V** 呼出。复制新的内容后，它会自动出现在历史列表；首次启动不会导入启动前的剪贴板。

也可以在「设置 → 呼出快捷键」选择 **双击 ⌘**：连续单独按下、松开 Command 两次，呼出或收起面板。左、右 Command 均可，间隔遵循系统双击速度；⌘C、⌘V 等组合键和中途点击鼠标不会触发。跨应用监听需要辅助功能权限。

点击其他应用或桌面后，面板会自动收起。打开设置、文本片段编辑或图片预览时，面板会保留，避免打断当前操作。

## 精简模式

点击搜索栏右侧的收起图标，或在设置中开启「精简模式」。精简窗口默认约 560 × 430，可调整大小，并与完整窗口分别记忆尺寸和位置。

拖动窗口调整大小后会自动保存；重新打开、退出重启或切换显示模式时，恢复该模式上次的尺寸。设置等弹窗造成的临时尺寸变化不会覆盖这些记录。

- 左侧只显示分类图标，右侧只显示历史列表和搜索，不显示详情预览。
- 单击立即选择记录，双击直接粘贴；原有键盘快捷键和右键菜单仍可使用。
- 图片记录最前面显示 84 × 56 的完整比例小图，不裁切；缩略图单独压缩缓存，粘贴仍使用原图。
- 鼠标停留在记录上约 0.35 秒可查看悬浮详情：完整文字 / 片段、图片、文件名称与路径，以及来源和时间。详情按内容在 280 × 140 至 560 × 480 之间调整，屏幕空间不足时进一步收缩；长文字和长图片可移入详情框滚动查看，离开后自动收起。
- 常驻图片详情与悬浮详情使用独立的显示尺寸预览，减少大图解码内存；放大查看和再次粘贴仍使用原图。
- 保留记录摘要、来源、时间；全部记录用「历史 / 收藏 / 片段」小标记区分。
- 压缩顶部、列表间距和底部，不展示快捷键说明、操作指引、成功提示和常驻状态文字。
- 底部仅在有权限问题或错误时出现提示。右上角展开图标可切回完整模式。

两种模式都只在左下角保留一个设置入口。

| 操作 | 快捷键 |
| --- | --- |
| 呼出 / 收起 Qpaste | ⇧⌘V（设置中可换） |
| 搜索 | ⌘F |
| 上下选择 | ↑ / ↓ |
| 粘贴回原应用 | ↩，或双击记录 |
| 纯文本粘贴 / 粘贴文件路径 | ⇧↩ |
| 复制选中记录 | ⌘C |
| 复制为纯文本 | ⇧⌘C |
| 粘贴前 9 条搜索结果 | ⌘1 … ⌘9 |
| 收藏 / 取消收藏 | ⌘D |
| 新建文本片段 | ⌘N |
| 保存正在编辑的片段 | ⌘S |
| 删除选中记录 | ⌘⌫ |
| 设置 | ⌘, |
| 收起窗口 | Esc / ⌘W |

「全部记录」统一显示并搜索历史、收藏和文本片段，支持内容、文件名、来源应用和片段名称；空格分隔的关键词会同时匹配。收藏和片段仍可通过各自分类单独查看。预览文字中选取一段再按 ⌘C，会复制选区。

列表按「今天、昨天、近 7 天、近 30 天」分组，更早的记录按月份展示；各分组互不重叠，组内最新优先。分组标题不占用键盘选择或数字快捷键的位置。日期以 Mac 当前时区的自然日计算，跨午夜、唤醒及再次打开面板时刷新。片段按修改时间展示，其他内容按复制时间展示。

搜索旁的日历按钮可筛选「全部时间、今天、近 7 天、近 30 天」或自定义起止日期，包含起止两天。日期范围可与关键词、内容分类一起使用，并可一键清除。历史按范围内的复制时间和当时来源匹配，同一内容只显示一次；片段按修改时间匹配。筛选只影响展示，不触发清理。

列表每批加载 80 条摘要，滚动或按向下键到达末尾时自动加载更多，无需翻页。选中或悬浮查看时才在后台读取完整正文；最近查看的正文最多缓存 12 条、约 8 MB。连续下滑不再把所有历史正文留在内存里。搜索仍查询整个数据库，容量与分类条数始终统计全部记录。复制、粘贴和片段编辑使用完整内容，编辑和删除不影响尚未加载的历史；保存失败的捕获内容暂存在内存并自动重试。

## 功能

- **文本与链接**：自动分类，保留可用的 RTF 格式；纯文本粘贴会去掉格式。
- **图片**：保存 PNG 副本，支持缩略图、透明背景预览、点击放大与缩放，再次复制时提供 PNG / TIFF。
- **文件**：支持多个文件、名称与路径预览、在 Finder 中显示。历史保留的是文件位置，不会备份原文件；原文件被移动或删除后，仍可复制旧路径。
- **收藏**：常用历史不会被自动清理。
- **文本片段**：文字记录右上角或右键菜单选择「存为文本片段」，可命名和编辑，也可用 ⌘N 新建。片段独立于普通历史，清空历史时保留。
- **本机存储**：不联网、不调用 AI、不上传内容。按个人使用要求，带敏感标记的剪贴板内容同样记录。
- **控制记录**：随时暂停；暂停期间的内容不会在恢复时补录。
- **容量与期限**：默认保存最近 300 条 / 30 天。条数可选 100、300、500、1000 或「不限」；不限条数时，容量和时间清理仍生效。普通历史最多 5 GB（5 × 1024³ 字节）；收藏和片段不受自动清理限制。
- **容量统计**：设置中显示普通历史的已用容量 / 5 GB、容量进度条、收藏与文本片段的额外容量和内容合计。统计与清理额度使用相同的内容大小口径，不含存储索引；文件记录只计算路径，不计算原文件大小。普通历史触发条数、时间、容量任一限制时会清理，收藏和片段不占用普通历史额度。

## 直接粘贴权限

「直接粘贴」通过 macOS 键盘事件把 ⌘V 发送到刚才的应用，需要在「系统设置 → 隐私与安全性 → 辅助功能」中开启 Qpaste。应用首次尝试直接粘贴时会说明并提供设置入口。

未授权时，历史记录、搜索、预览、片段和复制仍可用；切回目标应用按 ⌘V 即可。启用登录启动前，建议先将应用移到最终使用的位置。

## 存储

```
~/Library/Application Support/Qpaste/
├── history.sqlite
├── history.json  # 升级前的原始历史备份（如存在）
└── images/
```

目录权限为 `0700`，数据库和图片文件为 `0600`，内容未额外加密。旧 JSON 历史自动迁入 SQLite，原文件保留，迁移成功后不会再次导入。删除记录会同时删除关联的复制时间，成功保存后清理不再引用的图片。历史文件无法解析时先保留原文件备份，不直接覆盖它。设置中可以打开存储位置。

相同内容只保留一份，每次捕获到新的复制会单独保存时间和来源；浏览、收藏、复制还原和直接粘贴不增加捕获事件。文本片段使用独立的修改时间。旧历史迁移只使用已知的首次和最近复制时间，不推测中间事件；首次来源无法恢复时显示未知应用。

单条文本上限 2 MB；图片上限 20 MB、4000 万像素、单边 16384 像素。暂不提供 OCR、云同步、富 HTML 归档或文件备份。轮询间隔为 0.5 秒，间隔内快速连续复制的中间内容可能不会被记录。

## 构建与测试

需要 macOS 14+、支持 Swift 6 的 Xcode 或 Command Line Tools。无第三方依赖。

```sh
# 首次配置本机签名（钥匙串可能要求确认）
bash scripts/setup-signing.sh
# 每次更新
bash scripts/build-app.sh
bash scripts/install-app.sh
# 代码测试
bash scripts/test.sh
# 固定签名回归：两个不同程序版本、身份冒用、内容篡改和证书缺失
bash scripts/test-signing.sh
```

构建脚本会生成图标，并用同一张本地代码签名证书签署 `dist/Qpaste.app`。签名身份绑定 `app.qpaste.mac` 和证书指纹，不绑定某次构建的代码哈希；证书缺失、私钥不可用或证书未受信任时会停止，不会退回临时签名。构建及安装前均验证签名。安装脚本先正常退出旧进程，再替换完整应用包并启动。

从旧临时签名首次切换过来，需要为 `/Applications/Qpaste.app` 重新授权一次辅助功能。后续使用同一证书、相同应用标识更新，预期保留授权；如更换证书或重置系统隐私权限，仍可能需要重新授权。真实效果以跨版本直接粘贴和双击 ⌘ 验证为准。这是个人本机签名，未做 Developer ID 签名和公证，不用于跨机器公开发布。

证书与私钥存入登录钥匙串，仅预先允许系统 `codesign` 工具访问签名密钥；信任范围限当前用户的代码签名。初始化脚本可重复运行，会复用或恢复已有身份，不会自动生成替代证书。有效期为 10 年。

本地恢复材料保存在 `~/Library/Application Support/QpasteSigning/`，与剪贴板历史和代码仓库分离：`certificate.pem` 为公开证书，`identity-backup.p12` 为加密的证书与私钥备份，`backup-password.txt` 为恢复密码。目录权限为 `0700`，文件为 `0600`。**两个备份文件放在一起即可恢复私钥，整个目录须视为密钥保护；需要异机备份时放入加密存储，不要提交到仓库或分享。** 删除或重建证书会改变应用身份。

签名工具默认使用登录钥匙串和上述目录；隔离验证可通过 `QPASTE_SIGNING_KEYCHAIN`、`QPASTE_SIGNING_DIR` 指定其他位置。

测试使用独立命名的剪贴板与临时目录，不读写用户的系统剪贴板。测试覆盖历史去重、保留策略、敏感标记、纯文本还原、PNG 图片、多文件、暂停恢复、片段和存储错误。

当前版本的缺陷检查、合成数据性能结果和后续建议见 [检查报告](docs/AUDIT.md)。可单独运行隔离压力测量：

```sh
QPASTE_BENCHMARK=1 bash scripts/test.sh -c release --filter PerformanceTests
```

后续的正文按需读取、数据库升级和同样本内存对比见 [正文按需读取验证](docs/LAZY_CONTENT.md)。缓存额度按内容大小计算，当前显示 / 编辑的正文和图片、界面本身另需内存。

```sh
# 界面演示使用独立样例，不读取系统剪贴板
open -n dist/Qpaste.app --args --demo
```

结构：`QpasteCore` 负责记录模型、搜索、保留策略与文件存储；`Qpaste` 负责系统剪贴板、全局快捷键、目标应用切换、界面与设置。

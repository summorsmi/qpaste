# Qpaste

一个为个人使用设计的 macOS 原生剪贴板工具。菜单栏常驻，用快捷键找回复制过的内容。

## 开始使用

双击 `dist/Qpaste.app` 即可运行，也可以将它拖入「应用程序」。关闭窗口后应用仍在菜单栏运行，右键菜单栏图标可以暂停记录、打开设置或退出。

默认用 **⇧⌘V** 呼出。复制新的内容后，它会自动出现在历史列表；首次启动不会导入启动前的剪贴板。

也可以在「设置 → 呼出快捷键」选择 **双击 ⌘**：连续单独按下、松开 Command 两次，呼出或收起面板。左、右 Command 均可，间隔遵循系统双击速度；⌘C、⌘V 等组合键和中途点击鼠标不会触发。跨应用监听需要辅助功能权限。

点击其他应用或桌面后，面板会自动收起。打开设置、文本片段编辑或图片预览时，面板会保留，避免打断当前操作。

## 精简模式

点击搜索栏右侧的收起图标，或在设置中开启「精简模式」。精简窗口默认约 560 × 430，可调整大小，并与完整窗口分别记忆尺寸和位置。

拖动窗口调整大小后会自动保存；重新打开、退出重启或切换显示模式时，恢复该模式上次的尺寸。设置等弹窗造成的临时尺寸变化不会覆盖这些记录。

- 左侧只显示分类图标，右侧只显示历史列表和搜索，不显示详情预览。
- 单击立即选择记录，双击直接粘贴；原有键盘快捷键和右键菜单仍可使用。
- 图片记录最前面显示 84 × 56 的完整比例小图，不裁切；缩略图单独压缩缓存，粘贴仍使用原图。
- 鼠标停留在记录上约 0.35 秒可查看悬浮详情：完整文字 / 片段、图片、文件名称与路径，以及来源和时间。详情按内容在 280 × 140 至 560 × 480 之间调整，屏幕空间不足时进一步收缩；长文字和长图片可移入详情框滚动查看，离开后自动收起。
- 保留记录摘要、来源、时间；全部记录用「历史 / 收藏 / 片段」小标记区分。
- 压缩顶部、列表间距和底部，不展示快捷键说明、操作指引、成功提示和常驻状态文字。
- 底部仅在有权限问题或错误时出现提示。右上角展开图标可切回完整模式。

两种模式都只在左下角保留一个设置入口。

| 操作 | 快捷键 |
| --- | --- |
| 呼出 / 收起 Qpaste | ⇧⌘V（设置中可换） |
| 搜索 | ⌘F |
| 上下选择 | ↑ / ↓ |
| 粘贴回原应用 | ↩，或双击记录 |
| 纯文本粘贴 / 粘贴文件路径 | ⇧↩ |
| 复制选中记录 | ⌘C |
| 复制为纯文本 | ⇧⌘C |
| 粘贴前 9 条搜索结果 | ⌘1 … ⌘9 |
| 收藏 / 取消收藏 | ⌘D |
| 新建文本片段 | ⌘N |
| 保存正在编辑的片段 | ⌘S |
| 删除选中记录 | ⌘⌫ |
| 设置 | ⌘, |
| 收起窗口 | Esc / ⌘W |

「全部记录」统一显示并搜索历史、收藏和文本片段，支持内容、文件名、来源应用和片段名称；空格分隔的关键词会同时匹配。收藏和片段仍可通过各自分类单独查看。预览文字中选取一段再按 ⌘C，会复制选区。

## 功能

- **文本与链接**：自动分类，保留可用的 RTF 格式；纯文本粘贴会去掉格式。
- **图片**：保存 PNG 副本，支持缩略图、透明背景预览、点击放大与缩放，再次复制时提供 PNG / TIFF。
- **文件**：支持多个文件、名称与路径预览、在 Finder 中显示。历史保留的是文件位置，不会备份原文件；原文件被移动或删除后，仍可复制旧路径。
- **收藏**：常用历史不会被自动清理。
- **文本片段**：文字记录右上角或右键菜单选择「存为文本片段」，可命名和编辑，也可用 ⌘N 新建。片段独立于普通历史，清空历史时保留。
- **本机存储**：不联网、不调用 AI、不上传内容。按个人使用要求，带敏感标记的剪贴板内容同样记录。
- **控制记录**：随时暂停；暂停期间的内容不会在恢复时补录。
- **容量与期限**：默认保存最近 300 条 / 30 天。条数可选 100、300、500、1000 或「不限」；不限条数时，容量和时间清理仍生效。普通历史最多 5 GB（5 × 1024³ 字节）；收藏和片段不受自动清理限制。
- **容量统计**：设置中显示普通历史的已用容量 / 5 GB、容量进度条、收藏与文本片段的额外容量和内容合计。统计与清理额度使用相同的内容大小口径，不含存储索引；文件记录只计算路径，不计算原文件大小。普通历史触发条数、时间、容量任一限制时会清理，收藏和片段不占用普通历史额度。

## 直接粘贴权限

「直接粘贴」通过 macOS 键盘事件把 ⌘V 发送到刚才的应用，需要在「系统设置 → 隐私与安全性 → 辅助功能」中开启 Qpaste。应用首次尝试直接粘贴时会说明并提供设置入口。

未授权时，历史记录、搜索、预览、片段和复制仍可用；切回目标应用按 ⌘V 即可。启用登录启动前，建议先将应用移到最终使用的位置。

## 存储

```
~/Library/Application Support/Qpaste/
├── history.json
└── images/
```

目录权限为 `0700`，历史和图片文件为 `0600`，内容未额外加密。删除记录并成功保存后，会删除不再引用的图片副本。历史文件无法解析时先保留原文件备份，不直接覆盖它。设置中可以打开存储位置。

单条文本上限 2 MB；图片上限 20 MB、4000 万像素、单边 16384 像素。暂不提供 OCR、云同步、富 HTML 归档或文件备份。轮询间隔为 0.5 秒，间隔内快速连续复制的中间内容可能不会被记录。

## 构建与测试

需要 macOS 14+、支持 Swift 6 的 Xcode 或 Command Line Tools。无第三方依赖。

```sh
bash scripts/build-app.sh
bash scripts/test.sh
open dist/Qpaste.app
```

构建脚本会生成图标，并对 `dist/Qpaste.app` 进行本机临时签名。该产物可在本机运行，未做 Developer ID 签名和公证；不是用于跨机器发布的安装包。重新编译后，系统可能要求重新启用辅助功能权限。

测试使用独立命名的剪贴板与临时目录，不读写用户的系统剪贴板。测试覆盖历史去重、保留策略、敏感标记、纯文本还原、PNG 图片、多文件、暂停恢复、片段和存储错误。

```sh
# 界面演示使用独立样例，不读取系统剪贴板
open -n dist/Qpaste.app --args --demo
```

结构：`QpasteCore` 负责记录模型、搜索、保留策略与文件存储；`Qpaste` 负责系统剪贴板、全局快捷键、目标应用切换、界面与设置。
